# Beta Climb — регистрация пользователя

**Пустовой Георгий Юрьевич, Родманич Василий Александрович**

Сценарий: новый пользователь заполняет анкету регистрации. Профиль сохраняется в базе и доступен после обновления страницы.

**Клиент:**

1. Пользователь вводит ник, рост, вес, возраст, опыт, типы трасс, максимальную категорию, пол и отмечает согласие.
2. Форма проверяет обязательные поля и отправляет данные на бэкенд.
3. После сохранения открывается приветствие. Браузер запоминает идентификатор профиля, чтобы загружать его при следующем открытии. При ошибке введённые данные остаются в форме.

**Бэкенд:**

1. Cлой апи принимает запрос и проверяет корректность данных.
2. Слой бизнес-логики подготавливает профиль к сохранению.
3. Слой работы с данными через Spring Data сохраняет профиль в postgres.
4. Бэкенд возвращает сохранённый профиль и его идентификатор. При повторном запросе читает профиль из базы.

Таблица создаётся SQL-миграцией при запуске. Сохранение работает с реальной базой. Регистрация пока означает создание профиля: логина и пароля нет.

Запустить:

```sh
docker compose -f docker/docker-compose.yml up --build -d
```
