# Проверка прототипа на видео

Для проверки сняты два разных показателя. Сквозной прогон показывает, может ли пользователь получить и открыть результат. Размеченные контрольные видео показывают, насколько верно программа сопоставляет конечности и зацепки.

## Сквозной прогон

Три первых ролика переданы через multipart API. Локальные PostgreSQL и S3-совместимый эмулятор сохраняли попытки и артефакты, а текст рекомендаций возвращала реальная модель `glm-5.3-flash`. Количество карточек относится к указанному прогону. Ответы модели могут меняться.

| Запись | Длительность | Карточки | Особенности |
|---|---:|---:|---|
| [Rock Spot V3, Cryptic C62, CC BY-SA 3.0](https://commons.wikimedia.org/wiki/File:Indoor_Bouldering_V3_Rock_Spot.webm) | 45,9 с | 2 | Вертикальный кадр 204×360. На большинстве отсчётов карта стены не выровнена с текущим кадром. |
| [Анна Штёр в Анси, Shev123, CC0](https://commons.wikimedia.org/wiki/File:Anna_Stohr_JMM_2013_Annecy_Bloc.webm) | 25,03 с видеоданных | 1 | Камера движется и меняет масштаб. Исходный WebM имел несовпадающие длительности контейнера и видеодорожки. |
| [The Way Up, p3/orange, Anna Maschek и David C. Schedl, CC BY 4.0](https://zenodo.org/records/15196867) | 38,67 с после нормализации | 3 | Стабилизированная запись 720×1280. В Chrome карточка открыла исходный эпизод с 16,6 с и подсветила связанную зацепку. |

На всех трёх роликах вернулся статус `limited` с конкретными ограничениями. Другой браузер получил HTTP 404 при запросе чужого видео. У владельца запрос диапазона вернул HTTP 206 с байтами MP4. Повреждённый файл перешёл в `rejected`. Проверка карточек проверяет наличие измерения, интервала и источника в данных. Практическую полезность советов тренер пока не оценивал.

После перехода на модели SQLAlchemy и расширения справочника повторили полный сценарий на отдельной записи p9/green из The Way Up (59,27 с). API вернул HTTP 202, все восемь задач в PostgreSQL завершились успешно. Статус попытки — `ready`. В финальном прогоне GLM выбрала три эпизода. На 11,8–12,4 с на изображении правая стопа находилась рядом с контуром зацепки в сумме 0,6 с. В карточке приведены три источника, в мобильном Chrome нажатие запустило этот фрагмент с 11,8 с. Кнопка карты показала 13 зацепок предполагаемой зелёной трассы на начальном кадре. Для каждого совета отдельно сверили границы видео, текст измеренного наблюдения и ссылки на публикации выбранных принципов.

Локальный сквозной прогон использовал реальную GLM и локальные PostgreSQL и S3. В Timeweb отдельная проверка в транзакции только для чтения подтвердила наличие четырёх таблиц, соответствующих моделям воркера, и успешную миграцию V5. В приватном бакете Yandex Object Storage `betaclimb` проверены запись тестового объекта, чтение его содержимого и удаление.

## Предполагаемые контакты

Использованы опубликованные аннотации [The Way Up](https://zenodo.org/records/15196867). Метрика требует правильной конечности, той же зацепки и temporal IoU не менее 0,5. Для клипов длиннее минуты видео и эталон обрезались до 60 секунд. В таблице результаты сервисного воркера с нормализацией записи.

| Видео | Precision событий | Recall событий |
|---|---:|---:|
| p3/orange | 22,6% | 20,0% |
| p4/green | 20,5% | 25,0% |
| p5/green | 13,5% | 19,2% |
| p8/orange | 15,6% | 15,6% |

Таблица выше получена прежним декодером.

### Новый декодер на видео

Три записи The Way Up прошли этапы воркера от нормализации до выбора трассы без подсказок. Оба декодера получили одни и те же маски и позы. В ячейках precision / recall событий.

| Видео | Прежний декодер | Новый декодер | Руки, новый | Стопы, новый | Цвет трассы |
|---|---:|---:|---:|---:|---|
| p2a/orange, разработка | 25,0% / 25,0% | 64,5% / 50,0% | 55,6% / 47,6% | 76,9% / 52,6% | Оранжевый, верно |
| p3/orange | 22,6% / 20,0% | 74,1% / 57,1% | 64,3% / 50,0% | 84,6% / 64,7% | Оранжевый, верно |
| p4/green, первые 60 с | 20,5% / 25,0% | 94,7% / 56,2% | 92,9% / 68,4% | 100% / 38,5% | Зелёный, верно |

На всех трёх записях цвет подтвердился, и сопоставление повторилось по зацепкам трассы. Полноту теперь ограничивает распознавание цвета. У 3–9 зацепок размеченной трассы цвет остался `unknown`, и они выпали из сопоставления. На p4 так потеряны 8 из 13 контактов стоп. Цвет не определён примерно у половины зацепок стены, поэтому добавление всех `unknown` к трассе снижает precision до 48–53%. Параметры декодера подбирались по этим же записям. Новых участников с замороженными настройками ещё не проверяли.

### Новый декодер на сохранённых позах

Декодер больше не отбрасывает точки кистей и стоп по visibility. В контрольных записях этот порог исключал 75–94% моментов контакта рук, хотя в 73–85% таких кадров точка кисти находилась в пределах 20 px от нужной зацепки. Контакт теперь требует неподвижной конечности, удерживает текущую зацепку при колебаниях к соседней, допускает разрыв до 1 с и длится не менее 0,8 с. Доля времени с низкой visibility сохраняется в `lowVisibilitySec` каждого события. Когда цвет трассы подтверждён контактами на всей стене, сопоставление повторяется только по зацепкам этого цвета.

Проверка использует сохранённые маски и позы RatPoC и тот же критерий событий. Этот расчёт не требует видео и моделей.

| Видео | Прежний декодер | Новый, вся стена | Новый, трасса известна |
|---|---:|---:|---:|
| p2a/orange, разработка | 28,2% / 27,5% | 40,0% / 45,0% | 64,7% / 55,0% |
| p3/orange | 25,9% / 20,0% | 48,6% / 51,4% | 81,8% / 77,1% |
| p4/green | 25,0% / 28,1% | 31,7% / 40,6% | 96,3% / 81,2% |

В ячейках precision / recall событий. Параметры подбирались по этим же трём записям одной стены, поэтому значения оптимистичны и требуют проверки на новых участниках с замороженными настройками. В сохранённых результатах нет цветов зацепок. В последнем столбце зацепки, совпавшие с размеченной трассой, получили один цвет, то есть выбор трассы считался верным. Автоматический выбор цвета измерен в таблице выше. Повторить расчёт можно из `backend/worker` командами `poetry run python evaluation/check_contacts.py` и с флагом `--known-route`.

Новые участники p5 и p8 сняты на той же стене. У двух роликов с Wikimedia нет экспертной разметки контактов. Значения precision и recall для них не вычислялись.

## Цвет трассы

На The Way Up проверили, удаётся ли автоматически отличить зацепки маршрута от соседних зацепок другого цвета. На вход поступали карта стены и последовательность предполагаемых контактов. Название ролика и эталонная трасса в вычислениях не участвовали. Для длинных записей использовали первые 60 секунд. Настройки выбора цвета зафиксировали до проверки на восьми новых записях.

| Участник | Истинный цвет | Результат |
|---|---|---|
| p6 | Зелёный | Не определён |
| p7 | Оранжевый | Не определён |
| p1 | Зелёный и оранжевый, две записи | Не определён в обоих случаях |
| p9 | Зелёный и оранжевый, две записи | Верно в обоих случаях |
| p10 | Зелёный и оранжевый, две записи | Зелёный определён верно, оранжевый не определён |

Три верных ответа, пять воздержаний. В этих восьми видео ошибочного цвета не было. Все записи сделаны на одной стене с двумя трассами, поэтому результат не характеризует точность на произвольном скалодроме. Для зелёной трассы p9 отдельно сравнили карту зацепок с разметкой. Из 13 предложенных зацепок совпали 12, всего авторы отметили 22. Использовано взаимно однозначное сопоставление прямоугольников при IoU ≥ 0,3. [The Way Up](https://zenodo.org/records/15196867)

## Сверка рекомендаций с тренерами

Ego-Exo4D публикует свободные комментарии о хороших движениях и советы по улучшению с таймкодом остановки видео. Для боулдеринга авторы указывают 65 тренировочных, 15 валидационных и 22 тестовых видео с этой разметкой. В статье, например, тренер связывает раскачивание после отрыва с положением удерживающей руки. Для первого сравнения выбрана валидационная часть. [Таблицы 18 и 20 публикации](https://research-information.bris.ac.uk/ws/portalfiles/portal/404924651/Ego_Exo_CVPR2024.pdf) · [Официальная схема](https://docs.ego-exo4d-data.org/annotations/proficiency_estimation/)

Сначала прототип обрабатывает запись с одной внешней камеры вслепую. Затем рецензент сравнивает видимость движения, момент события, объяснение и предложенное действие с экспертными комментариями. Тренер мог остановить видео уже после движения. У опубликованного эталона нет требования перечислить все ошибки. Лицензированные записи и аннотации этого набора в проекте отсутствуют. Точность тренерских рекомендаций на них пока не измерена. [Команда и протокол сверки](evaluation/README.md) · [Доступ к Ego-Exo4D](https://docs.ego-exo4d-data.org/getting-started/)
